# Silly Names
A plugin for RotorHazard

Randomly substitutes alternate text for pilot callsign during lap announcement  

## Installation

Install through the "Community Plugins" area within RotorHazard. Alternately, copy the `silly_names` directory from inside `custom_plugins` into the plugins directory of your RotorHazard data directory.

## Usage

- Open the `Pilots` panel on the `Format` page. Fill in the `Silly Name (Phonetic)` field for pilots as appopriate. Names are never displayed as text, so use a phonetic spelling to adjust pronunciation.
- If desired, adjust the frequency from the `Silly Name` panel on the `Settings` page.
- Pilot names will be (randomly) replaced during lap callouts
